"The Himalayan Cafe" Website

It is a simple cafe shop website offering various coffees online as well as in-store, including other food products, which you can look up through the menu option. Here, i have first made a simple website using HTML and CSS, then added the functionality of the website using Java , and finally, I have used PHP and MySQL to create a database for the website to store user information, login, ordering items, making reservations and giving feedback.

Skills: HTML, CSS, Java, PHP, MySQL, MAMP & GITHUB
